# TIC-TAC YRP
Repositorio con el objetivo de llevar acabo el desarrollo del proyecto de la problematica de movilidad en Aguascalientes 
# TIC-TAC RUTA

# OBJETIVO DEL PROYECTO
Desarrollar un sistema digital basado en Python que permita monitorear en tiempo real los recorridos del transporte público en Aguascalientes, vinculando el inicio de la jornada del chofer con una plataforma de consulta para el usuario, con el fin de reducir el tiempo de espera innecesario y mejorar la eficiencia del servicio público.
Se enfoca en la creación de programa funcional que demuestre que la tecnología puede llegar ser maravillosa. El alcance incluye:
•	Programación de la lógica del sistema en Python para el cálculo de tiempos de recorrido.
•	 Diseño de un panel básico de visualización para que el usuario final consulte los tiempos de espera.
